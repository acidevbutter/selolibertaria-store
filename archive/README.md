# Selo Libertária — archive

Non-git material from the cancelled Selo Libertária project, preserved before the codebase was converted
into a client store template (2026-10-10). Not part of the application; do not deploy.

- `Selo Libertaria/` — Claude Design canvases, tokens, UI kits, assets
- `backup/`, `conteudo/` — exported site content and images
- `docs/`, `history/`, `memory/`, `output/`, `outputs/`, `tmp/`, `.claude/` — project docs, session history, reports
- `store-untracked/` — e2e specs that were never committed
- `wip/` — uncommitted diff from the `editorial-published-content` worktree
- Excluded on purpose: `.env*`, `settings.local.json`, `.codex-*` run logs, `node_modules`, `.DS_Store`

Unmerged branches and stashes of both repos are under `archive/*` branches and `refs/archive/stash-*`.
