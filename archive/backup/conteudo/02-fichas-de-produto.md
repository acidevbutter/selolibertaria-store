### Linha de abertura
> Primeiro livro da trilogia *s3xo são paulo* de literatura erótica criada por Natália Nolli Sasso.

### Sinopse
> *Ninfas do Tietê* recria uma cidade dentro de outra cidade: é uma São Paulo das Ninfas, mulheres soltas pelas ruas e imaginários de uma cidade vibrante, pulsante, e ao mesmo tempo tensa e desejosa.
>
> O livro é um convite aberto ao leitor e à leitora para mergulhar nas águas de um rio Tietê habitado por criaturas e Ninfas, e por paixões que saltam e assombram ruas, rios, sonhos e espaços da cidade de São Paulo.
>
> Escrito originalmente em 2016, no contexto do Golpe contra a então Presidenta Dilma Rousseff, teve sua primeira edição publicada em 2018. Está hoje na segunda edição revisada, com ilustrações especialmente criadas pela artista Vanusa Passos.

## Schema JSON-LD — modelo por PDP

Colar em cada página de produto, trocando os valores. Usar `Book` + `Product` juntos: `Book` alimenta resultados ricos de livro, `Product` alimenta o preço.

```json
{
  "@context": "https://schema.org",
  "@type": ["Book", "Product"],
  "name": "Ninfas do Tietê",
  "author": {
    "@type": "Person",
    "name": "Natália Nolli Sasso",
    "url": "https://selolibertaria.com.br/about"
  },
  "publisher": { "@type": "Organization", "name": "Selo Libertária" },
  "bookFormat": "https://schema.org/Paperback",
  "bookEdition": "2ª edição revisada",
  "datePublished": "2021",
  "inLanguage": "pt-BR",
  "numberOfPages": 60,
  "isbn": "9788592579814",
  "image": "https://selolibertaria.com.br/assets/livro-ninfas-do-tiete-capa.webp",
  "description": "Primeiro livro da trilogia s3xo são paulo. Uma São Paulo das Ninfas, mulheres soltas pelas ruas e imaginários de uma cidade vibrante, tensa e desejosa.",
  "genre": ["Poesia", "Literatura erótica"],
  "contributor": { "@type": "Person", "name": "Vanusa Passos", "jobTitle": "Ilustradora" },
  "isPartOf": { "@type": "BookSeries", "name": "s3xo são paulo" },
  "offers": {
    "@type": "Offer",
    "price": "49.00",
    "priceCurrency": "BRL",
    "availability": "https://schema.org/InStock",
    "url": "https://selolibertaria.com.br/products/ninfas-do-tiete",
    "seller": { "@type": "Organization", "name": "Selo Libertária" }
  }
}
```
